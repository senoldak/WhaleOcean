# Eksiksiz ve Kusursuz Türkçe Dil Desteği Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Whale Ocean terminali genelinde %100 dinamik Türkçe ve İngilizce dil desteği sağlamak; Pods, Hunt, Trails, Reef, Migration, Graveyard, Okyanus kartları, fiyat grafiği, olay akışı ve sayfa başlıklarındaki tüm hardcoded İngilizce metinleri tip güvenli `useTranslation()` mimarisine taşımak.

**Architecture:** `src/i18n/types.ts` üzerinde eksik tüm modüllerin tip tanımlarını yapmak; `tr.ts` ve `en.ts` dosyalarında %100 key parity ile profesyonel finansal/okyanus terminolojisini tanımlamak; Server Component sayfalarındaki sabit başlıkları dinamik istemci bileşenlerine entegre ederek tek tıkla anında dil değişimini sağlamak; `tests/i18n.test.ts` ve UI testleriyle regresyonsuz doğrulamak.

**Tech Stack:** Next.js 15, React 19, TypeScript, Vitest, Tailwind CSS, Lucide React.

## Global Constraints

- Varsayılan dil kalıcı olarak Türkçe (`'tr'`) olmalıdır.
- `tr.ts` ve `en.ts` arasında %100 anahtar denkliği (key parity) zorunludur. Hiçbir anahtar eksik veya boş bırakılamaz.
- Tüm sayfa başlıkları ve metrik etiketleri sayfa yenilenmeden dinamik olarak güncellenmelidir.
- Kripto varlık simgeleri (BTC, ETH, SOL vb.) ve protokol isimleri (Hyperliquid) orijinal haliyle korunmalıdır.
- Mevcut 100 testin tamamı yeşil kalmalıdır.
